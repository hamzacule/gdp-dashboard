Blink an LED with Arduino UNO

Learn to control a digital output to blink an LED.

  1. Connect an LED with a 220Ω resistor to pin 13.
  2. Open Arduino IDE and select Arduino UNO board.
  3. Paste the code below and upload.
// Arduino Blink
void setup() { pinMode(13, OUTPUT); }
void loop() { digitalWrite(13, HIGH); delay(1000); digitalWrite(13, LOW); delay(1000); }
Read Temperature with DHT22

Use a library to read temperature and humidity.

  1. Wire VCC to 5V, GND to GND, DATA to pin 2 with a 10k pull‑up.
  2. Install the DHT sensor library (e.g., Adafruit DHT).
  3. Upload the example sketch and open Serial Monitor.
Control a Servo (SG90)

Rotate a servo to a specific angle.

  1. Power servo from 5V and GND, signal to pin 9.
  2. Use the Servo library to write angles.
  3. Test sweeping from 0° to 180°.
