Components

Key components for Arduino projects with quick specs and usage tips.

Sensors

DHT22 (Temp/Humidity)

Digital sensor for temperature and humidity.

  • Voltage: 3.3–5V
  • Temp range: -40 to 80°C
  • Humidity: 0–100% RH
DigitalSingle-wire

HC-SR04 (Ultrasonic)

Measures distance using ultrasonic pulses.

  • Voltage: 5V
  • Range: 2–400 cm
  • Interface: TRIG/ECHO
TimingEcho

MPU6050 (IMU)

6-axis accelerometer + gyroscope.

  • Voltage: 3.3–5V
  • Interface: I²C
  • Address: 0x68/0x69
I²CGyro

Motors & Drivers

DC Motor + L298N

Control direction and speed using PWM and H-bridge.

  • Voltage: 5–12V motor
  • Driver: L298N (dual)
PWMH-bridge

Servo SG90

Position control with 50 Hz PWM signal.

  • Voltage: 4.8–6V
  • Angle: ~180°
PWMServo

Stepper + A4988

Precise steps with microstepping driver.

  • Voltage: per stepper
  • Microsteps: up to 1/16
Step/DirDriver

Modules

ESP32 DevKit

Wi‑Fi/Bluetooth MCU for IoT.

  • Voltage: 3.3V
  • Wi‑Fi: 2.4 GHz
  • BLE: Yes
Wi‑FiBLE

OLED 0.96" I²C

Small display for text/graphics.

  • Voltage: 3.3–5V
  • Interface: I²C
  • Resolution: 128×64
I²CDisplay

Relay Module

Switch high‑voltage loads safely.

  • Signal: 5V
  • Contacts: NO/NC
IsolationSafety
